# Technology built to keep going.

Durante builds software and AI-assisted workflows that connect the work to its context, decisions and history. People set the direction, review the results and decide what happens next.

## What we're working on

- **[DuranteOS](https://duranteos.com/)** — also called Durante, a workspace for following AI-assisted work across sessions. It is in use in our own work, in development and available through restricted access.
- **[Altyaa](https://altyaa.ai/)** — a SaaS product in production, with agents that prepare recommendations and actions for people to review.
- **[AdCore Turbo](https://www.adcore.com.br/)** — an existing product-data platform undergoing migration and evolution.

## In the open

Explore our [public repositories](https://github.com/orgs/durante-tech/repositories?type=public). [mood-signal-agent](https://github.com/durante-tech/mood-signal-agent) is a small proof of concept for an agent using MCP tools; its example data is synthetic and it does not deliver notifications.
